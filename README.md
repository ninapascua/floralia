> **Floralia** is a floral arrangement workshop studio website designed to inspire creativity and introduce visitors to the art of floristry. It presents workshop programs, membership information, and studio details through a visually engaging and accessible web experience.

---

## Overview

**Floralia** is a responsive, single-page website developed using HTML, CSS, and JavaScript as an academic web development project.

The website represents a floral arrangement studio offering workshops for individuals interested in learning floristry, from beginners exploring floral design to experienced enthusiasts looking to improve their skills.

Floralia combines visual storytelling, creative typography, floral imagery, and organized content to establish a distinctive identity while providing visitors with information about the studio's services.

The project emphasizes interface design, responsive layouts, and user-friendly navigation.

## Features

### 1. Creative Landing Page

The homepage introduces Floralia through a visually distinctive design.

Key elements include:

- Floral-inspired visual identity.
- Custom typography and decorative elements.
- Studio branding and introductory tagline.
- Navigation links to the main website sections.

### 2. Membership Information

The Membership section introduces the studio's community and workshop benefits.

Visitors can explore information about:

- Early access to class schedules.
- Hands-on floral arrangement workshops.
- Provided floristry kits and materials.
- Priority booking for special events.
- Member-exclusive activities and content.

A **Join Now** button directs interested visitors to an external Google Form for registration.

### 3. Floral Arrangement Classes

The website presents three workshop levels designed for different experience levels.

| Workshop | Level | Duration | Price |
|---|---|---|---|
| Class of Amaryllis | Beginner | 4 hours | ₱4,000 |
| Class of Delphinium | Intermediate | 5 hours | ₱5,500 |
| Class of Gladiolus | Advanced | 6 hours | ₱7,000 |

Each class includes a designated floristry kit, workshop materials, and other benefits.

The comparison table helps visitors review the available options based on their experience and interests.

### 4. About the Studio

The About section introduces Floralia's creative philosophy and approach to floral arrangement.

The studio emphasizes:

- Creativity and artistic expression.
- Practical floral arrangement techniques.
- Mindfulness through floral design.
- Appreciation for nature.
- Sustainable floristry practices.

### 5. Promotional Video

The About section incorporates an HTML5 video featuring:

- Built-in playback controls.
- Looping playback.
- A custom poster image.
- English captions using a WebVTT file.

### 6. Responsive Navigation

The website includes navigation links for:

- Home
- Membership
- Classes
- About

A mobile navigation menu uses JavaScript to display and hide navigation links on smaller screens.

### 7. Contact and Inquiry Form

The website includes an inquiry form where visitors can enter:

- Full name
- Email address
- Questions or concerns

The form includes required-field validation and a reset option.

The repository does not establish a connected backend or message-delivery service for the form.

## UI/UX Design

Floralia emphasizes a creative and visually cohesive interface that reflects the nature of its subject.

### Design Approach

- **Visual Identity** – Floral imagery, elegant typography, and decorative elements communicate the studio's creative identity.
- **Typography** – Custom serif fonts establish an artistic and editorial aesthetic.
- **Color and Composition** – Coordinated backgrounds, overlays, and visual elements create a distinctive presentation.
- **Content Organization** – Clearly separated sections introduce the studio, membership benefits, and workshop offerings.
- **Responsive Design** – CSS media queries adapt selected layouts and navigation elements for different screen sizes.
- **Navigation** – Section-based links and a collapsible mobile menu support website exploration.

## Getting Started

### Prerequisites

The website requires:

- A modern web browser, such as Chrome, Firefox, Edge, or Safari.
- Git (optional, for cloning the repository).
- An internet connection for externally hosted fonts, icons, and the membership form.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ninapascua/floralia.git
cd floralia
```

**2. Open the website**

Open `index.html` in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code to preview the website locally.

**3. Explore the website**

Navigate through the Home, Membership, Classes, and About sections.

No backend installation or database configuration is required for the static website.
